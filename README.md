## 🚀 Getting Started Locally

### Prerequisites
- Python 3.9+ or modern web browser

### Running the App
1. Clone the repository:
   ```bash
   git clone https://github.com/Zaidjm1/ai-developer-portfolio.git
   cd ai-developer-portfolio
   ```

2. Run the local development server:
   ```bash
   python server.py
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8088
   ```
